一回戦対戦用Bot
https://www.procon-asahikawa.org/files/U16asahikawaBot.zip

製作：U16旭川プログラミングコンテスト実行委員会
shimomura@kyokko.ed.jp

実行に必要なライブラリ
.NET Framework4.5 (ほとんどのWindowsには自動的に入っていると思います。）

開発環境
Microsoft VisualStuido 2017 Professional

使用方法
１，付属のバッチファイルを利用する
a:サーバーのIPアドレス p:ポート番号 n:名前

２，実行ファイルをダブルクリックもしくはコマンドプロンプト起動する。
起動後は対話的に各種パラメータを入力して下さい。
